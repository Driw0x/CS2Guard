# CS2Guard - Projet de vérification anti-triche côté serveur

<a id="purpose"></a>
## Objectif

Ce document suivra le développement du **CS2Guard Vérification anti-triche côté serveur**.

La composante côté serveur correspond à la phase de développement **v2.x** du CS2Guard.

Contrairement à l'Analyseur de démo, qui analyse des matchs de Counter-Strike 2 enregistrés hors ligne, cette composante vise à analyser le comportement des joueurs depuis le côté serveur pendant une partie en direct.

Ce document sera complété au fur et à mesure que l'architecture côté serveur, les fonctionnalités, les décisions techniques et les stratégies de test seront mises en œuvre.

---

<a id="current-status"></a>
## État actuel

**Non commencé.**

L'axe actuel de développement est le **CS2Guard Analyseur de démo (v1.x)**.
