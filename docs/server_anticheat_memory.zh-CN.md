# CS2Guard - 服务器端反作弊项目内存

<a id="purpose"></a>
## 目的

本文件将跟踪 **CS2Guard 服务器端反作弊** 的开发进程。

服务器端组件对应于 CS2Guard 的 **v2.x** 开发阶段。

与 Demo Analyzer 不同，后者是离线分析记录的《反恐精英 2》对战录像，本组件旨在在实时对战过程中从服务器端分析玩家行为。

随着服务器端架构、功能、技术决策和测试策略的实施，本文件将逐步扩展。
