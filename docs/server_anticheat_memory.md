# CS2Guard — Server-Side Anti-Cheat Project Memory

## Purpose

This document will track the development of the **CS2Guard Server-Side Anti-Cheat**.

The server-side component corresponds to the **v2.x** development phase of CS2Guard.

Unlike the Demo Analyzer, which analyzes recorded Counter-Strike 2 matches offline, this component is intended to analyze player behavior from the server side during live gameplay.

This document will be expanded as the server-side architecture, features, technical decisions, and testing strategies are implemented.

---

## Current Status

**Not started.**

The current development focus is the **CS2Guard Demo Analyzer (v1.x)**.
